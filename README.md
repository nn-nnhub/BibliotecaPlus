# BibliotecaPlus

BibliotecaPlus es un sistema Java para gestionar libros, usuarios y préstamos de una biblioteca.

## Tecnologías

- Java 17
- Spring Boot
- Maven
- Spring Data JPA
- H2

## Objetivo inicial

Construir una versión funcional pequeña y evolucionarla mediante mantenimiento, refactorización y gestión de configuración.
