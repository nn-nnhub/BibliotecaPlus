# Formato de documentación de un RFC

**Nombre:** `RFC-NNN-tema-del-cambio.md`, con un tema breve y descriptivo.

1. **Identificación y trazabilidad:** Issue, PR o indicación de que no existe PR, estado de integración y responsables cuando estén confirmados.
2. **Objetivo y justificación:** problema, motivo y alcance.
3. **Implementación e impacto:** solución, módulos afectados y límites.
4. **Pruebas y evidencias:** comandos, ambiente, resultados comprobados y enlaces a capturas o registros. Separar resultados históricos de la validación vigente.
5. **Registro detallado:** conservar análisis, código anterior, resultados, decisiones, riesgos y referencias originales. No inventar datos ausentes.

La solicitud en GitHub usa además la [plantilla de issue](../.github/ISSUE_TEMPLATE/rfc.md). Los documentos auxiliares conservan sus secciones según su finalidad.
